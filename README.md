# ルートランナー

iPhone のホーム画面に追加して、機内モードでも遊べる横スクロール・オートランナー。
素の HTML / CSS / JavaScript（ES Modules）だけで動き、外部通信はしません。画像も音もコードで作っています。

## 遊び方（まずはここだけ）

1. タイトルをタップすると拠点。拠点は下のタブで「拠点」「装備」「所持品」を切り替える。
2. 「出撃する」で冒険へ。その下の **次の目標** に、いまやると良いことが1つ出る。迷ったらそれをタップ。
3. 冒険では、主人公は自動で走って攻撃する。**画面タップでジャンプ**（長押しで高く・2段まで）。
4. レベルアップしたら3枚のカードからスキルを1つ選ぶ。拾った装備は「所持品」で比べて付ける。
5. 2000m の炎竜を倒すと「踏破」。次の難易度が開く。
6. 拾ったゴールドと素材で、村の **施設** を建てて育てる（村の絵の建物をタップ）。**実績** の報酬を受け取ると、称号とマントが手に入る（主人公をタップで着替え）。

## くわしい遊び方

- 画面タップでジャンプ。短く押すと低く、長押しで高く跳ぶ。空中でもう1回押すと2段目（少し低め）。
  着地の直前に押した分は、着地と同時に跳ぶ。攻撃は自動。
- 落ちながら敵の頭に乗ると「踏みつけ」で大ダメージ＋もう一度跳ね上がる。
- 敵の見分け方（初めて会った敵は画面に短い説明が出る）：
  - スライム・投石兵・低く飛ぶコウモリ … 跳んで越える（または踏む）
  - 高く飛ぶコウモリ … 長押しの大ジャンプで当たる。くぐるなら短く跳ぶ
  - 投石兵の「！」→ 赤い輪の場所に岩が落ちて転がってくる … 転がってきたら跳ぶ
  - 盾兵 … 地上から斬ると盾で防がれる（20%）。踏むか、跳んで空中から斬る
  - 突進イノシシ … 立ち止まって「！」のあと一気に突っ込んでくる。跳んで越える
  - 大スライム … 倒すと普通のスライム2匹に分かれる
  - もぐら … 地中を進む土の盛り上がり。赤く光ったら真下から飛び出すので跳ぶ
  - 自爆ボム … 近づくと光って地面に赤い輪 → 爆発。跳ぶか、その前に倒す（倒すと周りの敵を巻き込む）
  - さまよう霊 … 上下にゆっくり漂う。低いときは跳び、高いときは跳ばない
  - エリート … 金色に光る強い敵（特性：速い・硬い・トゲ・再生）。トゲは踏むと反撃される。良い装備を必ず落とす
- エリア（500mごと）と仕掛け：
  - みどりの丘（宝箱：壊すとゴールド・ときどき装備）→ 夕焼けの荒野（流砂：踏むとダメージ。跳び越える）
    → 月夜の森（霧：遠くが見えにくい。「！」は霧の上に出る）→ 灼熱の火山（噴き出し口：光ったら火柱。跳び越える）
- ボス（各エリアの終わり）。HPバーの真ん中の線を切ると第2形態になり、攻撃が変わる：
  - キングスライム … 跳ねると衝撃波（地面の赤い帯）。小スライムを吐く。第2形態は衝撃波が2連続
  - 岩石ゴーレム … 岩を投げる・衝撃波。第2形態は大岩（大きく跳ぶ）
  - 森の魔女 … 弾を撃つ。点線が出た高さに来る（赤＝低い：跳ぶ／青＝高い：跳ばない）。霊を呼ぶ
  - 炎竜 … 足元が光ったら火柱（跳ぶ）。低い火の玉（跳ぶ）
- **踏破と難易度**：2000m の炎竜を倒すと「踏破」で出撃が終わり、次の難易度が解放される（最大5）。
  難易度が1つ上がるごとに敵のHP×1.8・攻撃力×1.3、敵Lv（拾う装備のアイテムLv）+5。付与効果の階級は難易度2でT6、難易度3でT7まで出る。
- **チェックポイント**：倒したボスの位置（500/1000/1500m）から出撃できる。スキルはその分のレベルアップをまとめて選ぶ。
  ただし途中からだと、雑魚のドロップ50%・ボスの装備1個（0mからなら2個）・踏破報酬（エピック以上1つ）なし。
- 倒した敵は経験値の結晶を落とす（自動で吸い寄せる）。レベルが上がると3枚のカードから1つ選ぶ。
  - 攻撃スキル（最大4つ）：回転刃・落雷・火炎瓶・着地衝撃・魔弾・冷気
    ＋訓練所で解放：障壁（補助）・ブーメラン・聖域・地雷・光線・時の砂（補助）
  - 強化スキル（最大4つ）：力・連射・範囲・生命・多重・跳躍 ＋訓練所で解放：守り・鋭さ・引力・爆薬・集中・幸運
  - 3枚のうち1枚は、持っている攻撃スキルの強化（か進化）が必ず入る
  - 攻撃スキルを Lv5 にして、対の強化スキル（カードに「進化：Lv5＋○○」と表示）を持っていると、進化カードが出る（12種）
  - 補助スキルは敵を倒す力が弱いかわりにボス戦で役立つ（障壁：攻撃を1回防ぐ／時の砂：敵と弾が遅くなり、受けるダメージ+25%）
  - 訓練所を上げると、引き直し（1回の出撃で最大3回）・最初に持って出るスキル・出さないスキルの指定ができる
  - スキルは出撃ごとにリセット。威力は装備と関係なく、敵のレベルに合わせて伸びる
- **装備とスキルの役割**
  - 装備＝本体の強さ。武器の攻撃・踏みつけ・会心・HP・防御。**ボスにはスキルが効かない**ので、ボスは装備で倒す
  - スキル＝群れを倒す力。武器は1回に近い3体までしか斬れず、群れの小さいスライムは踏めないので、大群はスキルで崩す
  - 投石兵にはスキルが効きにくい（約1/3）
- ときどき「大群が来る！」の予告のあと、小さいスライムが固まった壁が何度も来る。
  小さいスライムは体当たりすると消えるが、止めきれないと続けて当たる。
- 群れの小さいスライムの体当たりは、防御があっても最大HPの10%以上のダメージになる。
- ボスは70秒以内に倒す。40秒で怒って攻撃が速く・強くなり（HPバーの下に残り秒数）、70秒で最後の一撃を受けて出撃が終わる。
- 拾った装備を拠点で比べて、装備・強化・鍛冶・分解する。
  - 装備枠：武器・頭・胴・装飾×2。武器は剣（3体まで斬る）・斧（遅いが5体・重い）・短剣（速い・会心・1体）・弓・杖
  - 付与効果は25種・階級T1〜T5（アイテムLvが高いほど上位が出る。難易度2以上で拾うとT6・T7も）。条件付きの効果もある（ジャンプ中・HP50%以下・ボス・無傷の敵 など）
  - セット（疾風・鉄壁・狩人・黄金）は2/3/4個でボーナス。レジェンドは17種（図鑑で確認）
  - 鍛冶：付与効果の行をタップして選び「数値を再抽選（安い）」「別の効果に付け替え」「これを残して他を引き直す（高い）」。
    素材（欠片・結晶・宝玉・秘石・星核）は分解で手に入り、付け替え・固定・+6以上の強化に使う
  - 所持品は部位・レア度で絞り込み、並び替えができる。枠はゴールドで増やせる（最大150）。
    「拾ったときに自動分解」を設定すると、そのレア度以下を拾った瞬間に分解する（セット・レジェンド・戦力が上がるものは残す）
- **拠点の村**：施設が建物として並び、レベルで 空き地 → テント → 小屋 → 家 → 石造り と育つ（最大で旗が金色）。
  建物をタップするとその施設、主人公をタップすると見た目（称号・マント）。空は端末の時刻で朝・昼・夕・夜になる。
  強化できる施設には小さな矢印が出る。
- **次の目標**：所持品がいっぱい → 戦力が上がる装備 → 強化できる施設 → 次のボス → 近い実績 の順に1つだけ出す。
- **実績** は達成したらその場で報酬（ゴールド・素材・称号）を受け取る（結果の画面と拠点のお知らせに出る）。
- **所持品がいっぱいのとき**：レジェンド・セット・戦力が上がる装備・エピックを拾ったら、持っている中で一番弱いもの（保護・セット・レジェンド以外）を分解して空ける。
  空けられないときは、レジェンド・セット・戦力が上がるものだけ枠を10個までこえて持つ（レジェンドは必ず残す）。それ以外は拾った瞬間に分解。
- **見た目**：兜・鎧・装飾は付けている装備のレア度で絵が変わる（冒険中も）。マントは受け取った実績の数（3・6・10・14・18・23・29・36件）で8色。
  称号は実績ごとに1つ（〈踏破者〉など）。
- **やり込み**（拠点の「出撃する」の下の4つのボタン）
  - 日替わり：端末の日付で決まるコース（エリアの順・敵の並び・仕掛け・その日の条件2つ）。同じ日なら何度でも同じ。
    ボスを倒すと節目（500/1000/1500/2000m）の報酬を1日1回ずつ。難易度は踏破した一番上。チェックポイントと難易度の解放には数えない
  - 施設：ゴールドと素材で強化。訓練所（スキル）・鍛冶屋（鍛冶が安い）・倉庫（分解の収益）・道場（HP・攻撃力）・金庫（ゴールド）
  - 実績：36個。達成するとその場で報酬（ゴールド・素材・称号）を受け取る
  - 記録：出撃回数・冒険した時間・撃破数・稼いだゴールドなど
- 拠点右上の歯車（設定）：
  - 音：すべてオフ／BGM の音量／効果音の音量（別々）。iPhone のマナーモード中は鳴らない。冒険中は画面下の「音」ボタンでも切り替えられる。
    BGM はエリアごと・ボス戦・拠点で曲が変わる（Web Audio でその場で作る）。
  - 画面の揺れ・ダメージの数字のオン／オフ。
  - 省電力モード（下の「電池について」）。
  - ボタンを左に：冒険中の「音」「一時停止」を左下に置く（左手で持つとき）。ジャンプは画面のどこをタップしてもよい。
  - セーブの書き出し・読み込み・初期化、オフラインの状態。

## 電池について（長いフライト向け）

いつもしていること：
- 一時停止中・レベルアップの3択の間・結果の画面では、最後の1枚を描いたら描画を止める。
- 拠点の画面は描き続けない。村の絵の動き（たき火・旗・煙）は1秒に10回だけ、拠点タブが見えているときだけ。所持品・装備タブでは止まる。
- アプリが裏に回ったら一時停止し、音の処理も止める。消音中・BGM の音量0のときは BGM を作らない（消音中は音の処理ごと止める）。
- 画面の細かさは最大2倍まで。光のぼかしは重い処理（shadowBlur）を使わず、作り置きの画像を使い回す。
- セーブは中身が変わったときだけ書き込む。

省電力モードをオンにすると、さらに：
- 冒険の描画を1秒に30回に（ゲームの進み方は同じ）。画面の細かさを1倍に。粒の演出を半分に。
- 拠点の村の絵とタイトルの絵を止める。

さらに電池を持たせたいとき：画面の明るさを下げる・BGM の音量を0にする・機内モードにする（通信が止まる）。

```
css/style.css
js/main.js             起動・自動保存・デバッグ用 window.T
js/data.js             装備・エリアのデータ（RAR / WTYPES / AFFIX / UNIQUE / ZONES）
js/items.js            装備ロジック（genItem / computeStats など）
js/save.js             セーブ（版番号・移行処理・書き出し/読み込み）
js/base.js             拠点画面（renderBase / openItem）
js/settings.js         設定シート
js/run.js              冒険の更新処理（startRun / step / jump）
js/render.js           冒険の描画（draw）
js/audio.js            効果音と BGM（Web Audio でその場で合成。曲はデータから作る）
js/title.js            タイトル画面
js/camp.js             拠点の村の絵（施設の建物・立っている主人公）
js/hero.js             主人公の見た目（マント・兜・肩当て・首飾り）。冒険と拠点で共通
js/icons.js            絵のアイコン（装備・素材・施設。SVG をコードで持つ）
js/skills.js           出撃中のスキル（経験値・レベルアップの3択・進化）
js/meta.js             やり込み要素の処理（施設・実績・記録・日替わりダンジョン）
js/hub.js              やり込み要素の画面（施設・実績・記録・日替わり）
js/offline.js          service worker の登録
js/ui.js / util.js     共通の小道具
icons/                 アイコン（tools/make-icons.html で生成）
tools/                 アイコン生成ページ（アプリ本体には含めない）
archive/               分割前の1ファイル版（参考用。アプリ本体には含めない）
```

`index.html` をダブルクリックで開いても動きません（ES Modules はサーバー経由でないと読めないため）。下のどちらかの方法で開いてください。

## iPhone で遊ぶ：GitHub Pages で公開する（おすすめ）

https で配信されるので、オフライン起動（service worker）が有効になります。

> 注意：無料の GitHub アカウントで Pages を使うには、リポジトリを **Public** にする必要があります。
> コードは誰でも見られる状態になります（URL を知らなければ見つかりにくい、という程度）。
> 見せたくない場合は GitHub Pro（有料）で Private リポジトリから公開できます。

### 初回

1. GitHub にログインし、右上の「+」→「New repository」。
   - Repository name：例 `lootrunner`
   - Public を選び、「Create repository」。
2. ファイルを上げる。どちらか一方で。
   - **ブラウザで**：作ったリポジトリの「uploading an existing file」を開き、
     `lootrunner-prototype` フォルダの **中身**（`index.html` などが一番上に来るように）をドラッグして「Commit changes」。
     フォルダごとドラッグすると、URL が1階層深くなるだけで動きはします。
   - **ターミナルで**：
     ```sh
     cd lootrunner-prototype
     git init
     git add .
     git commit -m "最初の版"
     git branch -M main
     git remote add origin https://github.com/<ユーザー名>/lootrunner.git
     git push -u origin main
     ```
3. リポジトリの「Settings」→ 左の「Pages」。
   - Source：「Deploy from a branch」
   - Branch：「main」と「/ (root)」を選んで「Save」。
4. 1〜2分待つと、同じ画面の上に `https://<ユーザー名>.github.io/lootrunner/` が表示される。

### iPhone に入れる

1. iPhone の **Safari** で上の URL を開く（Chrome アプリなどではなく Safari）。
2. 共有ボタン →「ホーム画面に追加」→「追加」。
3. ホーム画面のアイコンから **一度オンラインのまま** 起動する。
4. 拠点右上の「設定」→「オフライン」が「有効」になっていることを確認する。
   「準備中」なら、アプリを上にスワイプして閉じてから開き直す。
5. 機内モードにして、アイコンから起動できれば完了。

### 更新するとき

1. ファイルを直したら、`sw.js` の先頭の `VERSION` を上げる（例 `'1.7.0'` → `'1.7.1'`）。
   `js/main.js` の `APP_VERSION`（タイトル画面に出る番号）も同じにする。
   ファイルを増やしたときは `sw.js` の `ASSETS` にも足す。
2. GitHub に上げる（ブラウザでアップロードし直すか、`git add . && git commit -m "…" && git push`）。
3. 数分待ってから、iPhone でオンラインのままアプリを開く。
   裏で新しい版が届くと「新しい版を受け取りました」と出る。
4. アプリを閉じて開き直すと新しい版になる（「設定」→「新しい版にする」でもよい）。

`VERSION` を上げ忘れると、iPhone では古い版がずっと使われます。

## 同じ Wi-Fi 内の Mac から配信して試す

手早く iPhone で動きを見たいとき用。**http なのでオフライン起動は有効になりません**
（service worker は https か localhost でしか動かないため）。遊び心地の確認用と考えてください。

1. Mac のターミナルで：
   ```sh
   cd lootrunner-prototype
   python3 -m http.server 8000
   ```
   「受信接続を許可しますか」と聞かれたら許可する。
2. Mac の IP アドレスを調べる：
   ```sh
   ipconfig getifaddr en0
   ```
   （例 `192.168.1.23`。出なければ「システム設定」→「Wi-Fi」→ 接続中のネットワークの「詳細」）
3. iPhone の Safari で `http://192.168.1.23:8000/` を開く。
4. 終わったらターミナルで `Ctrl + C`。

Mac のブラウザで `http://localhost:8000/` を開いた場合は service worker も動くので、
Chrome の DevTools →「Network」→「Offline」にしてリロードすると、オフライン起動を確認できます。

> 開発中のヒント：キャッシュ優先で動くので、ファイルを直してもリロードだけでは古いままのことがあります。
> DevTools →「Application」→「Service workers」の「Update on reload」をオンにしておくと楽です。

## セーブについて

- 保存先は端末内（localStorage）。装備を拾ったとき・拠点で操作したとき・5秒ごと・アプリが裏に回ったときに保存します。
- **ホーム画面のアイコンを削除すると、そのアプリのセーブも消えます。** Safari のタブで開いたときのセーブとも別です。
- **バックアップのしかた**（機種変更・消失に備えて、大きな更新の前やフライトの前に）：
  1. 拠点右上の歯車 →「セーブを書き出す」→「テキストをコピー」。
  2. メモアプリなどに貼り付けて保存する（`LOOTRUNNER1:` で始まる長い1行）。
  3. 戻すときは、歯車 →「セーブを読み込む」の欄に貼り付けて「貼り付けたセーブを読み込む」。今のデータは上書きされる。
  古い版で書き出したテキストも、新しい版で読み込める（自動で新しい形式に直す）。逆（新しい版のテキストを古い版で）は読めない。
- セーブの形式を変えるときは `js/save.js` の `SAVE_VERSION` を上げ、`MIGRATIONS` に古い形式からの変換を足します。
  読めなかったセーブは `lootrunner-save-v1-broken-<時刻>` という別名で残します。

## デバッグ

ブラウザのコンソールで `window.T` からゲームの状態と主な関数を触れます。

```js
T.SAVE                // セーブデータ
T.startRun({diff:1, start:0})   // 出撃（難易度・出発地点。省略すると前回の選択）
T.R.enemies.push(T.mkEnemy('boar', {elite:true}))   // 敵を出す
T.step(1/60)          // 1フレーム進める
T.jump(); T.releaseJump()   // 押す・離す（すぐ離すと低いジャンプ）
T.pickSkill(0)        // レベルアップの3択を選ぶ（T.R.sk.choices）。T.rerollSkills() で引き直し
T.startRun({daily:true, key:'2026-11-24'})   // 日替わり（key を省くと今日）
T.META.dailyPlan('2026-11-24')   // その日のコースの決まり方（エリアの順・条件）
T.SAVE.fac.train = 10 // 施設のレベルを変える（訓練所10でスキルがすべて出る）
T.exportText()        // 書き出しテキスト
T.nextGoal()          // 「次の目標」に出るもの
T.openLook()          // 見た目（称号・マント）
T.SAVE.settings.eco = true; T.applySettings()   // 設定を変えて反映
T.bgmState()          // BGM の状態（どの曲・予約中か・音の処理の状態）
```
